# 명품익스프레스

**AI 기반 이사 자동 견적 및 통합 관리 플랫폼**

> 정보시스템프로젝트캡스톤디자인 | CodeMove(코드무브) 팀  
> 분석·설계 문서(Use Case · 화면설계서 · ERD)를 기반으로 실제 시스템 구현을 준비하는 프로젝트입니다.

## 1. 프로젝트 소개

명품익스프레스는 고객이 **집 안 영상을 올리면 AI가 이삿짐 품목과 부피를 분석해 예상 견적을 알려주고**, 관리자는 **견적·예약·일정·상담·알림을 한곳에서 관리**할 수 있는 이삿짐센터 전용 정보시스템입니다.

현재 이삿짐센터 업무는 전화 상담과 수기 기록에 의존하고 있습니다. 견적서는 종이(A4)로 보관되어 외부에서 조회하기 어렵고, 일정은 휴대폰 연락처에 날짜만 적는 방식이라 예약 누락 위험이 있습니다. 이 프로젝트는 반복 상담과 1차 견적을 AI로 대신하고, 흩어진 견적·일정 데이터를 하나의 DB로 전산화하는 것을 목표로 합니다.

**핵심 차별점은 영상 기반 AI 견적과 관리자 업무 통합입니다.**

- 고객은 전화 없이 영상 한 번으로 예상 견적을 받고, AI가 인식한 품목을 직접 확인·수정할 수 있습니다.
- 이사 날짜를 정하지 못한 고객도 예상 금액 범위(최소~최대)를 확인할 수 있습니다.
- 홈 화면의 **진행상황 카드**로 접수 → 견적 → 예약 → 이사 완료까지 현재 단계를 한눈에 봅니다.
- 글자가 크고 단계가 단순한 **쉬운 모드**를 제공해 고령 고객도 혼자 견적을 받을 수 있습니다.
- 관리자는 종이 견적서를 촬영하거나 PDF로 올리면 AI가 내용을 읽어 디지털 견적서로 등록할 수 있습니다.

> AI 영상 분석과 챗봇은 현재 **화면 시연 단계**이며, 실제 AI 모델·외부 API 연동 방식은 검토 중입니다. 시연 데이터의 고객·견적·예약 정보는 가상 데이터입니다.

## 2. 프로젝트 목표

- 영상 기반 AI 분석으로 이삿짐 부피를 산출하고 비대면 예상 견적 제공
- 고객 견적 요청부터 관리자 견적 검토·승인, 예약, 계약금 결제, 후기까지 한 흐름으로 연결
- 수기 일정·종이 견적서를 웹 캘린더와 DB로 전산화하여 예약 누락 방지
- AI 챗봇과 상담원 채팅으로 반복 문의 응대 시간 단축
- 메시징 운영 설정과 알림 내역 관리로 고객 안내 업무 자동화
- 후기 관리로 신규 고객 신뢰 확보

### 4.3 상태 흐름

| 대상 | 상태 |
| --- | --- |
| 견적 요청 | 검토 중 → 견적 도착 → 견적 확정 / 만료 |
| 견적서 | 견적 검토 → 견적 승인 → 견적 확정 |
| 예약 | 승인 대기 → 예약 확정 → 이사 완료 / 예약 취소 |
| 결제 | 결제 대기 → 결제 완료 / 결제 취소 (계약금·잔금 구분) |

※ AI 예상 견적만으로는 예약이 확정되지 않습니다. 관리자가 영상과 품목을 검토해 최종 금액을 확정한 뒤 예약이 진행됩니다.

## 6. 개발 범위

**필수 구현**

- 회원가입·로그인(휴대전화 본인인증, 카카오·네이버·애플 간편 로그인) 및 권한별(고객/관리자) 화면 구분
- 홈 진행상황 카드로 견적 요청 접수부터 견적 도착, 예약 확정, 이사 완료까지 현재 단계 안내
- 영상 업로드, AI 품목·부피 분석 및 품목 수정, 이사 정보·주소·날짜 입력 후 예상 견적 제공
- 내 이사에서 예약·견적·완료 내역 확인, 견적 상세 확인 및 견적 확정, 예약 상세 확인·취소
- AI 챗봇 퀵메뉴 답변, 상담사 연결 및 사진·파일 첨부
- 이사 완료 후 별점·후기·사진 작성 및 내가 쓴 후기 조회
- 관리자 견적 관리(견적 검토·승인·확정, 품목·옵션·비용 수정, 고객 영상 확인)
- 관리자 채팅 관리(고객 상담 응대, 챗봇 운영 시간·인사말·퀵메뉴·답변 설정)
- 관리자 예약 관리(예약 목록·상세 확인, 계약금 결제 상태 관리)
- 관리자 리뷰 관리(고객 후기 조회 및 답변 작성)
- 관리자 알림 관리(발송 현황·알림 내역 조회, 에티켓 시간·문자 대체 발송 설정)
- 수기 견적서 사진·PDF 첨부 → AI 인식 → 수정 후 디지털 견적서로 등록
- 데이터베이스 연동 및 서버 배포

**선택 구현**

- 쉬운 모드(큰 글씨, 음성 안내, 단계별 버튼 문구)
- 고객 알림 확인, 내 정보 수정(휴대폰 번호 변경), 견적내역·예약내역 조회
- 관리자 대시보드(예약·리뷰·견적 현황, 주간 예약 그래프), 통합 메뉴 검색, 알림 패널
- 캘린더 기반 일정 관리(공휴일·손 없는 날 표시, 일정 등록, 업체 휴무일·예약 불가 날짜 설정)
- 회원 관리(회원 검색·등록·삭제, 권한 변경)

**제외 범위**

- 비회원 로그인 및 예약 조회(예약 번호·일회용 비밀번호)
- 고객의 거주 인원·평수·엘리베이터/사다리차 사용 여부 입력
- 예상 견적의 필요 톤수·투입 인부 수 표시
- 관리자 예약 승인·반려 처리(견적 승인으로 대체)
- 일정 기준 자동 알림 규칙 설정(예약 1시간 전·이사 전날 등)
- 확정된 견적서 자동 서명
- 전자 계약서 자동 생성 및 전자서명
- 집 내부 3D 인테리어 시각화
- 사후 접수
