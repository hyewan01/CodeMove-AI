# 대표님 통화 정리: 견적 내는 방법 (2026-11-23)

44분 45초 통화 녹음을 받아쓰기(Whisper large-v3-turbo)해서 정리했습니다. 처음 받은 AI 통화 요약과 다른 부분은 [5장](#5-ai-통화-요약과-다른-점)에 모았습니다. 이 문서의 숫자는 [data/](data/) CSV와 [EstimateCalculator](../../src/main/java/com/codemove/estimate/EstimateCalculator.java)에 반영했습니다.

## 1. 방문 견적 순서

1. 견적 문의가 오면 날짜·시간을 정하고, **도착 30분 전에 한 번 더 연락**한 뒤 방문합니다.
2. 이사 날짜, 이사를 자주 해 봤는지, 전에 한 이사는 마음에 들었는지 물으며 대화를 엽니다.
3. **안방부터 방마다** 짐을 체크합니다.
   - 안방: 가구, 옷·드레스룸 옷(옷 박스가 몇 개 나올지), 에어컨을 가져가는지
   - 거실 → 주방: 가전제품, **렌탈 제품**이 있는지
   - 작은 방: 아이 방인지 옷방인지 용도 확인
4. 렌탈 제품은 고객이 **이사 날짜에 맞춰 렌탈 업체에 미리 이전 예약**하도록 안내합니다.
5. 차가 몇 대 필요한지, **사다리차로 할지 엘리베이터로 할지** 고객과 정합니다.
6. 짐 양에 따라 몇 톤인지, 인원(예: 5톤이면 남자 3명 + 여자 1명)과 가격을 설명합니다.
7. 이전에 한 이사 사진을 보여 주며 작업 방식을 설명합니다.
8. 계약서를 써 주고 **계약금 10%**를 받습니다. 바로 정하지 않는 고객에게는 "생각해 보시고 연락 주세요"로 마무리합니다.
9. **이사 전날** 다시 연락해 고객이 준비할 것(인터넷·도시가스·관리사무소 연락, 두고 갈 물건)과 다음 날 도착 시간을 확인합니다.

## 2. 짐 양(CBM)과 톤

| 기준 | 값 |
| --- | --- |
| 1톤 | **10 CBM** = 바구니 50~70개 = 장롱(농) 5자. 짐이 많으면 꽉 채워 싣습니다 |
| 5톤 | **35 CBM** |
| 우리 집 예시 | 5톤 1대 + 1톤 2대 = **7톤 = 55 CBM** |
| 톤 단계 | 1톤, 2.5톤, 3.5톤, 5톤, 6톤, 7톤, 10톤 … |

- **"톤"은 차가 아니라 짐 양**입니다. 1톤 분량 짐을 2.5톤 차로 옮겨도 요금은 1톤 짐 기준입니다.
- **가구만 계산하면 안 됩니다.** 가구 속 물건을 꺼내 바구니에 담으면 새로 생기는 바구니도 따로 셉니다.
  - 서랍장 속 옷은 서랍째 옮기므로 꺼내지 않습니다.
  - TV장 서랍 한 칸이 가득이면 바구니 1~2개.
  - 주방 수납장 칸마다 바구니가 나오고, 냄비가 많으면 2~3개, 접시·그릇은 1~2개 정도 더 나옵니다.
- **바구니**에는 전자레인지만 한 물건과 잡동사니를 넣습니다. **파란 중박스**에는 옷, 선풍기 2대, 침대 옆 협탁 1개 정도가 들어갑니다.
- 대표님 경험상 AI(챗봇)에 사진과 **가구 하나(예: TV)의 실제 치수**를 알려 주면 나머지 가구 CBM을 "거의 맞게" 계산합니다. 나중에 고객에게 기준 치수 하나를 받는 기능으로 쓸 수 있습니다.
- 견적서에는 **선풍기 같은 작은 것까지 전부** 적습니다.

## 3. 요금

가격은 **아정당 평균가**를 기준으로 하고, 대표님 노하우를 더합니다. 대표님은 "가격이 딱 얼마가 아니라 **얼마에서 얼마**로 정해져 있다"고 했습니다.

**작업 내용 4가지**: 일반, 반포장, 포장, 보관 (견적서 작업 내용 칸)

| 짐 양 | 반포장 | 포장 |
| --- | --- | --- |
| 1톤 | 작업자 1명, 30~40만 원 | 작업자 1명, 50~60만 원 |
| 2.5톤 | 작업자 2명, 80~90만 원 | 작업자 2명 + 주방 1명, 100~110만 원 |
| 5톤 | (통화에 없음) | 150만 원 안팎, 남 3명 + 여 1명 |

**거리**: 50km마다 1톤 15만 원, 2.5톤 20만 원씩 추가 (아정당 기준, 대표님 "맞아"). 아정당 표: 50km 1톤 15만·2.5톤 20만, 100km 30만·40만, 150km 40만·60만.

**옵션(기술이 필요한 작업, 별도)**

| 옵션 | 금액 |
| --- | --- |
| 벽걸이 TV | 55인치 5~7만, 65인치 7~10만, 75인치 15~17만, 85인치 23~25만, 100인치 약 45만 원 |
| 안마의자 | 대당 10만 원 |
| 에어컨 | 벽걸이·스탠드 대당 25만 원. **천장형(시스템)은 이전 불가** |
| 침대 | 일반 침대는 이삿짐에 포함. 안마형·모션 침대는 10~15만 원 |

**별도 비용**: 사다리차를 바로 댈 수 없어 짐을 50~200m 날라야 하는 등 여건이 어려우면 인원을 더 넣고 **20만~50만 원** 별도. 견적서에는 금액 대신 "현장 여건에 따라 별도 비용이 발생할 수 있습니다" 문구를 넣습니다.

## 4. AI가 할 일과 사람이 할 일

| AI(앱) | 방문 견적(대표님) |
| --- | --- |
| 짐 체크, CBM 계산, 톤 산정, 아정당 평균가 기준 기본 견적 | 고가품 확인(수천만 원 매트리스, 수입 가구, 작가 액자, 한 개 수십만 원 그릇·도자기) |
| 렌탈 제품·고가로 보이는 물건·닫힌 수납장을 **메모로 알림** | 고객 성향(꼼꼼한 2중 포장 요구, 요구가 많은 고객) 판단 후 견적 추가 |
| | 위험 부담이 너무 크면 "차라리 안 하는 게 낫다"는 판단 |

대표님: "가격은 평균적으로 거기에 맞추면 되고, 아빠의 생각과 결합시키는 거지." "AI가 고객 성향이나 제품을 직접 못 보니까 그건 아빠가 방문해서 결정하는 거지."

## 5. AI 통화 요약과 다른 점

| AI 요약 | 녹음 확인 결과 |
| --- | --- |
| "TV 크기에 따라 5만 원에서 25만 원까지" | 100인치는 **약 45만 원**까지 있음. 인치별 금액은 3장 표 |
| "안마의자, 에어컨 등은 고정 비용" | 맞음. 금액: 안마의자 **10만**, 에어컨 **25만**(대당). 천장형 에어컨은 이전 불가 |
| "포장이사 1t당 작업자 1명 50~60만 원, 2.5t 2명 100만 원 이상" | 2.5톤은 **작업자 2명 + 주방 1명, 100~110만 원** |
| "반포장 1t당 작업자 1명, 3~40만 원" | 맞음. 2.5톤 반포장 **작업자 2명, 80~90만 원**이 빠짐 |
| "AI가 사진과 치수를 입력받아 CBM 계산 지원" | 정확히는 **가구 하나의 실제 치수만** 알려 주면 나머지는 AI가 사진에서 비례로 계산한다는 경험담 |
| (없음) | 1톤 = **바구니 50~70개 = 장롱 5자**, 5톤 = 35 CBM, 우리 집 = **5톤 + 1톤 2대 = 55 CBM** |
| (없음) | "톤"은 **차가 아니라 짐 양** |
| (없음) | 가구 속 물건을 꺼내면 바구니를 **따로 더 계산**. 서랍장 옷은 그대로 |
| (없음) | 별도 비용 20만~50만 원(사다리 불가·장거리 운반)과 견적서 안내 문구 |
| (없음) | 계약금 10%, 이사 전날 확인 연락 내용 |

## 6. 통화에서 안 나온 값 → 아정당 기준으로 채움 (2026-11-24)

대표님이 "가격은 아정당 평균에 맞추면 된다"고 해서 아정당 자료로 채웠습니다. 아정당 체크리스트 PDF에는 톤별 가격이 없어 아정당 블로그·Q&A를 썼습니다.

| 항목 | 채운 값 | 출처 |
| --- | --- | --- |
| 포장 5톤 · 7.5톤 · 10톤 | 130~150만 · 190~210만 · 250~275만 원 (작업자 3+주방1 · 4+1 · 5+2) | 아정당 블로그 "5톤 130만~, 7.5톤 190만~, 10톤 250만~" + 대표님 5톤 150만. 상한은 +10% |
| 반포장 | 포장 − 20만 원 | 아정당 체크리스트: 반포장과 포장 차이는 작업자 1명, 최대 15~20만 원 |
| 보관이사 | 포장 × 1.5~2배 + 보관료 (5톤 하루 7천~1만 원, 톤 비례 × 일수) | 아정당 보관이사 글 |
| 5톤 거리 | 50km마다 30만 원 (기존 가정 유지) | 아정당 Q&A 사례(100km +20~50만, 150km +40~70만, 300km +150~180만, 400km +170~220만)와 맞음 |
| 날짜 할증 | 주말·월말 10%, 손 없는 날 20%, 손 없는 날 주말 30% | 아정당: 평일 < 주말·월말 < 손 없는 날 < 손 없는 날 주말(20~50% 이상) |
| 사다리차 | 층별 13.5만~51만 원 | 아정당 체크리스트 + 요금표 |
| 계단 작업 | 3개 층마다 인력 1명 15~20만 원 | 아정당 "인력 1명 15~20만 원, 층수에 따라 늘어남" (3개 층마다는 가정) |
| 엘리베이터 이용료 | 5~10만 원, 관리사무소에 고객이 냄 → 견적에 넣지 않고 안내 | 아정당 체크리스트 |

**아직 가정인 것 [업체 확인]**: 2.5톤·3.5톤 차의 CBM(20 · 25), 일반이사 요금 상한, 7.5톤·10톤 요금 상한(+10%), 계단 "3개 층마다 1명".
